# Triage labels

## Label mapping

| Role | Label |
|------|-------|
| Needs triage | `needs-triage` |
| Needs more info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

## Usage

- **needs-triage**: New issues that haven't been reviewed yet
- **needs-info**: Issues blocked waiting for clarification
- **ready-for-agent**: Issues that an agent can work on autonomously
- **ready-for-human**: Issues that need human judgment or action
- **wontfix**: Issues that won't be addressed

## Notes

These labels are used by the `triage` skill to classify and route issues.
